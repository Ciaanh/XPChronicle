# Changelog

All notable changes to XP Bar Enhanced will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2025-10-XX

### Changed

-   Simplified internal architecture for better performance and maintainability
-   Reduced code complexity through consolidation of service layers
-   Improved event handling with direct event patterns

### Fixed

-   Various bug fixes and stability improvements

## [1.0.0] - 2025-10-XX

### Added

-   Initial release
-   Two bar styles: Legacy (Blizzard-style) and Flat (modern, draggable)
-   Quest XP overlay visualization
-   Detailed tooltip with comprehensive XP information
-   Session statistics tracking
-   Fully customizable colors via color picker
-   Smart controls (Shift+Drag, Alt+Click, Ctrl+Click)
-   Options panel integration
-   Statistics window
-   Slash commands for configuration
