# XP Bar Enhanced

A World of Warcraft addon that replaces and enhances the default experience bar with richer visuals, quest XP overlays, session statistics, and full color customization.

**Retail only** · Interface 110207 · Version 1.0.0

## Features

- **Multiple Bar Styles** — Classic (Blizzard-style), Flat, Vertical, and Circular designs
- **Quest XP Overlay** — See pending quest XP directly on the bar
- **Session Tracking** — Track XP gained, time played, levels gained, and XP rate
- **Statistics Window** — Detailed breakdown of your leveling progress
- **Color Customization** — Full control over bar colors with preset themes
- **Minimap Button** — Quick access to options and stats

## Installation

1. Download and extract to your `Interface/AddOns` folder
2. Ensure the folder is named `XPBarEnhanced`
3. Start or reload World of Warcraft

## Slash Commands

| Command | Description |
|---------|-------------|
| `/xpbe` | Open the options panel |
| `/xpbe options` | Open the options panel |
| `/xpbe stats` | Open the statistics window |
| `/xpbe reset` | Reset session statistics |
| `/xpbe help` | Show available commands |

## Configuration

Access options via `/xpbe` or the minimap button. Settings include:

- **Bar Style** — Choose between classic, flat, vertical, or circular
- **Colors** — Customize XP bar, rested XP, quest XP overlay, and background
- **Presets** — Quick color themes (Default, Forest, Ocean, Sunset, Midnight)
- **Display** — Toggle rested XP display, quest XP overlay, and minimap button

## Requirements

- World of Warcraft Retail (The War Within)
- No external dependencies
